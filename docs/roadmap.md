# Roadmap — сделать сайт образцовым

Цель: портфолио сеньора, которое за первые секунды объясняет, чем Дмитрий ценен, а дальше
доказывает это кейсами, цифрами и качеством самого сайта.

Как вести список:

- Пункт закрывается тем же коммитом, который его делает: `- [ ]` → `- [x]` и ссылка на PR.
- 📥 — нужен материал от Дмитрия (тексты, цифры, скриншоты, решения). Пока его нет, пункт
  не начинаем, а переходим к следующему.
- Порядок важен: этап 0 определяет тексты и CTA всего остального.
- Новая идея — новая строка в нужном этапе, ничего не держим в голове.

      **«открыт к разговору»** (мягкий значок, не «Open to work»); локация как сейчас —

## Этап 2 — техническая витрина

- [x] **2.1 Prerender (SSG) всех маршрутов** — у каждого поста свой HTML с правильными
      OG-тегами; сейчас краулеры видят только общий `index.html`.
- [x] **2.2 SEO-база** — JSON-LD `Person` / `Article`, `sitemap.xml`, `robots.txt`, RSS.
      `robots.txt` сознательно не делаем: на `/dimacodehub/` его никто не читает (ADR 0013).
      Sitemap добавить в Google Search Console руками 📥
- [x] **2.3 OG-картинки для постов и кейсов.**
- [x] **2.4 View Transitions** (`withViewTransitions()`) вместо самописной анимации маршрутов,
      с переходом «карточка → заголовок».
- [x] **2.5 Тёмная и светлая тема** с переключателем и уважением к системной настройке.
- [x] **2.6 Страница «How this site is built»** — архитектура, ADR, Lighthouse, размер бандла,
      тесты и CI. Страница `/colophon`; размер бандла и число тестов меряет сборка
      (`build-stats.json`). Оценки Lighthouse добавятся вместе с 2.7.
- [x] **2.7 Lighthouse CI** в пайплайне с бюджетами. Свой скрипт на `lighthouse` вместо
      `@lhci/cli` (тот тянет старые уязвимые зависимости). Доступность, best practices и SEO —
      100 на всех страницах; производительность 85–88, порог 80. Дальше упирается в LCP:
      входные анимации из `opacity: 0` (hero, блог, пост) 📥 решение: менять ли анимации.
- [x] **2.8 Аналитика без cookies** — GoatCounter, без их скрипта: свой beacon на каждую
      навигацию, только с production-хоста. 📥 зарегистрировать сайт `dimacodehub` на
      goatcounter.com.
- [ ] **2.9 Блог** — подсветка кода, оглавление, фильтр по тегам, прогресс чтения.
